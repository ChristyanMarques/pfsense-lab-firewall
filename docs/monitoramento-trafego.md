# Monitoramento de Tráfego

## Objetivo
Monitorar o tráfego da rede utilizando o pfSense.

## Ferramenta utilizada

Status → Traffic Graph

## Teste realizado

Foi gerado tráfego a partir de uma máquina cliente utilizando ping e navegação.

## Resultado

O pfSense exibiu o aumento de tráfego nas interfaces de rede em tempo real.

## Conclusão

Foi possível validar o funcionamento da rede e observar o comportamento do tráfego.
